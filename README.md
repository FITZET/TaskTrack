# 任务指挥台

一个面向个人科研与项目工作的 Android 任务管理应用。它把人工重要性、DDL、流程依赖和提醒结合起来，帮助用户看到当前真正应该处理的事项，并自动保留可供 AI 月度复盘的事实记录。

## 当前功能

- 四个固定栏目：个人发展、项目工作、行程与行政、杂事
- 四级人工重要性：关键、重要、一般、可放弃
- 根据重要性、提醒期、逾期、阻塞关系动态排序，并解释排序原因
- 普通事项与多步骤流程，支持串行、并行依赖
- 内置“会议论文中稿后”和“期刊论文中稿后”模板
- 自定义模板语法：`步骤名称 | 距最终 DDL 天数 | 依赖步骤编号`
- 步骤可完成、跳过、取消或临时新增；父事项自动计算进度和完成状态
- 每个子步骤可独立新增、修改或清除 DDL
- 事项详情按待完成、已完成、已结束分区，步骤按 DDL 先后排列
- 首页突出事项总 DDL，并用红色显示所有当前可执行的下一步
- 支持 Android 系统侧边返回手势返回上一级页面
- 任务 DDL 日历
- 分级 Android 通知：关键和重要事项会在提醒期内逐级加强提醒
- 追加式事件日志：创建、开始、完成、重新打开、修改 DDL、跳过、取消和提醒触发
- 本月 Markdown/JSON 数据导出，可直接交给 AI 分析
- 完整 JSON 备份与恢复；同时参与 Android 系统备份和换机迁移
- 全部业务数据默认只保存在设备本地，无账户、无服务器、无遥测

## 构建

环境要求：JDK 17、Android SDK 35。

```powershell
.\gradlew.bat assembleDebug
.\gradlew.bat testDebugUnitTest lintDebug
```

调试 APK 输出在 `app/build/outputs/apk/debug/app-debug.apk`。

## 模板示例

```text
根据审稿意见修改论文 | 28 |
提交论文终稿         | 21 | 1
Copyright            | 18 | 2
注册                 | 14 | 3
提交 PPT             | 5  | 4
机票酒店安排          | 5  | 4
```

最后两项都依赖第 4 步，因此可以并行进行。依赖多个步骤时使用英文逗号分隔，例如 `1,3`。

## 数据说明

DDL 以所选日期当天 23:59:59 计算。跳过和取消的步骤不会进入自动进度分母，但事件会永久保留在复盘数据中。恢复备份会替换当前数据库，使用前应先导出一次现有备份。
